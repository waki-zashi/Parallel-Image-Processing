# Параллельная обработка изображений с использованием шаблона Producer–Consumer (C++)

## Общее описание

Данный проект представляет собой программу для **параллельной обработки изображений**, реализованную на языке **C++** с использованием шаблона **Producer–Consumer**.

Программа загружает изображение, выполняет выбранную операцию обработки и сохраняет результат в новый файл.

Цель проекта — продемонстрировать:

- принципы **параллельной обработки данных**
- **синхронизацию потоков**
- **масштабируемое распределение задач**
- использование **блокирующей очереди** для взаимодействия потоков

---

## Реализованные алгоритмы обработки

Программа поддерживает три режима обработки изображения:

### 1. Инверсия цветов

Каждый цвет пикселя инвертируется:

```

R = 255 - R
G = 255 - G
B = 255 - B

```

### 2. Увеличение яркости

Каждый цветовой канал увеличивается на фиксированное значение с ограничением диапазона `[0, 255]`.

### 3. Преобразование в оттенки серого

Оттенок серого вычисляется по формуле яркости:

```

Gray = 0.299 * R + 0.587 * G + 0.114 * B

```

После вычисления значение записывается во все три канала пикселя.

---

## Архитектура программы

Программа построена на основе паттерна **Producer–Consumer**.

### Producer (производитель)

Главный поток программы выполняет роль **producer**.  
Он разбивает изображение на блоки строк и формирует задачи.

Каждая задача содержит:

```

start_row
end_row

```

Задачи помещаются в **блокирующую очередь**.

---

### Consumer (потребители)

Несколько рабочих потоков выполняют роль **consumer**.

Каждый поток:

1. извлекает задачу из очереди
2. обрабатывает соответствующий блок изображения
3. записывает результат в выходной массив

---

## Блокирующая очередь

Для передачи задач между потоками реализована **потокобезопасная блокирующая очередь**.

Она основана на следующих механизмах:

- `std::queue` — хранение задач
- `std::mutex` — защита доступа к очереди
- `std::condition_variable` — блокировка потоков при пустой или переполненной очереди

Очередь поддерживает:

- ожидание появления задач
- ограничение максимального размера
- корректное завершение работы потоков

---

## Стратегия параллельной обработки

Изображение делится на **блоки строк** фиксированного размера.

Каждая задача содержит диапазон строк изображения, которые должен обработать поток.

Такой подход позволяет:

- равномерно распределять нагрузку между потоками
- эффективно использовать ресурсы процессора
- масштабировать производительность при увеличении числа потоков

---

## Синхронизация потоков

Для корректной работы многопоточной системы используются следующие механизмы:

- `std::mutex` — защита общей очереди задач
- `std::condition_variable` — ожидание появления задач
- `std::atomic<bool>` — сигнализация об ошибках между потоками

Очередь имеет механизм `finish()`, который корректно завершает работу всех потоков.

---

## Обработка ошибок

Программа содержит обработку исключений для следующих ситуаций:

- неверный путь к файлу изображения
- ошибка загрузки изображения
- некорректный размер изображения
- ошибка выполнения задачи в рабочем потоке
- некорректное количество потоков
- ошибка сохранения файла
- некорректный пользовательский ввод

Все исключения обрабатываются в функции `main()`.

---

## Измерение производительности

Для измерения времени выполнения используется:

```

std::chrono::high_resolution_clock

```

Программа сравнивает:

- **однопоточное выполнение**
- **многопоточное выполнение**

После чего выводит коэффициент ускорения:

```

Speedup = single_thread_time / parallel_time

```

## Используемые библиотеки

В проекте используются две сторонние библиотеки с одним заголовочным файлом:

### stb_image.h

Используется для **загрузки изображений**.

Поддерживаемые форматы:

- PNG
- JPEG
- BMP
- TGA

---

### stb_image_write.h

Используется для **сохранения изображений**.

Позволяет записывать изображения в формат PNG.

## Компиляция

Пример компиляции с использованием `g++`:

```

g++ -std=c++17 -O2 main.cpp -o image_processor -pthread

```

Параметр `-pthread` необходим для поддержки многопоточности.
